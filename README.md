# Customer_Shopping_Behavior_Analysis
📌 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer segments, product preferences, and revenue trends. The analysis was performed on 3,900 customer transactions across 18 features using Python, Pandas, PostgreSQL, and Power BI.

The project focuses on transforming raw customer data into meaningful business insights that can support customer retention, loyalty programs, subscription strategies, and targeted marketing decisions.

🛠️ Technologies Used
Python
Pandas
PostgreSQL
SQL
Power BI

🔍 Project Workflow
Data Cleaning
Checked and handled missing values.
Applied category-wise median imputation for missing review ratings.
Standardized column names using snake_case.
Feature Engineering
Created an age_group feature.
Created a purchase_frequency_days feature.
Prepared the dataset for further analysis.

SQL Analysis
Loaded the cleaned dataset into PostgreSQL.
Used SQL to answer 10+ business questions.
Analyzed revenue by gender and age group.
Identified high-spending discount users.
Analyzed product ratings and discount dependency.
Segmented customers into New, Returning, and Loyal groups.

Power BI Dashboard
Created an interactive dashboard.
Visualized revenue and sales by category.
Analyzed subscription status.
Compared customer behavior across age groups.
Presented insights in an easy-to-understand visual format.

📊 Key Business Insights

The analysis helps understand:

Customer purchasing behavior
Revenue contribution across different customer groups
Category-wise sales performance
Relationship between discounts and customer spending
Customer loyalty and repeat purchasing behavior
Subscription trends
Age-group purchasing patterns

💡 Business Recommendations

Based on the analysis, the project provides recommendations around:

Subscription programs to improve customer retention.
Loyalty programs to encourage repeat purchases.
Targeted marketing campaigns based on customer segments and purchasing behavior.
Better use of discount strategies to attract and retain customers.

🎯 Objective

The main objective of this project is to demonstrate how Python, SQL, PostgreSQL, and Power BI can be combined to clean, analyze, visualize, and communicate customer data effectively for business decision-making.
